# Vanilla JavaScript Projects 🚀

A collection of 20+ mini frontend projects built using HTML5, CSS3, and Vanilla JavaScript. These projects focus on DOM manipulation, event handling, user interaction, and modern UI/UX features.

---

### 01. **Color Changer**  
Changes the background color randomly on button click.  
Demonstrates basic DOM manipulation and event listeners.

### 02. **BMI Calculator**  
Calculates BMI based on user input height and weight.  
Includes conditional logic for BMI category results.

### 03. **Digital Clock**  
Displays real-time digital clock using JavaScript's Date object.  
Styled with CSS for a clean interface.

### 04. **Unlimited Colors**  
Generates random colors continuously.  
Uses `setInterval()` and dynamic CSS updates.

### 05. **Keyboard Key Detector**  
Detects key presses and displays their key code.  
Useful for learning key events and input handling.

### 07. **To-Do List**  
Create, delete, and complete tasks in a to-do list.  
Data is stored in localStorage for persistence.

### 08. **Quiz App**  
Multiple-choice quiz with score calculation.  
Uses array-based question objects and conditionals.

### 09. **Password Generator**  
Creates strong, random passwords using character options.  
Includes copy to clipboard feature.

### 10. **Notes App**  
Add, save, and delete notes with localStorage.  
Mimics a basic note-taking web app.

### 11. **Age Calculator**  
Calculates age from date of birth input.  
Simple math with JavaScript’s Date object.

### 13. **QR Code Generator**  
Generates QR codes based on user input.  
Uses a QR API for real-time generation.

### 14. **Music Player**  
Basic music player with play/pause and song switching.  
Uses audio element and DOM interaction.

### 15. **Stopwatch**  
Start, stop, and reset stopwatch timer.  
Uses intervals and conditional logic.

### 16. **Calculator**  
Fully functional calculator for basic operations.  
Handles user input, display, and evaluation.

### 17. **Popup Modal**  
Shows and hides a custom popup/modal.  
Uses CSS + JS for smooth transitions and UX.

### 18. **Show/Hide Password**  
Toggle visibility of password input fields.  
Improves form UX with simple toggling.

### 19. **Dark Mode Toggle**  
Switch between light and dark themes.  
Applies CSS classes dynamically with JS.

### 21. **Email Form with Google Forms**  
Frontend form that submits data via Google Forms.  
Great for simple contact form integrations.

### 22. **Password Strength Indicator**  
Shows strength level of password as you type.  
Analyzes character length and mix.

### 23. **Text to Speech Converter**  
Converts written text to audio output.  
Uses the Web Speech API for voice synthesis.

### 24. **Coming Soon Website**  
Simple landing page with countdown timer.  
Perfect for product launches or maintenance mode.

---

📌 All projects are beginner-friendly and showcase practical use of Vanilla JavaScript.
